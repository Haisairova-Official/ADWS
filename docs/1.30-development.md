## 使用 / Usage

打开统一设置 → 组件 → 任务栏样式。
Open Settings → Components → Taskbar Style.

- 上下左右四边；高度（竖栏宽度）24–160。双排最低 48。
- 应用窗口可双排，竖栏对应双列；开始、工作区、时钟和插件仍保持单排。
- 同应用窗口分组可关闭。数量角标表示窗口数；左键打开选择菜单，右键管理组内窗口。
- 悬停、聚焦、聚焦文字、提醒颜色可分别自定义或跟随主题。
- 窗口高亮过渡、设置页淡入淡出独立开关，默认关闭，时长 80–1000ms。
- 修改设置页动效后重新打开设置生效；歌词动效仍使用插件自己的开关。

- All four panel edges; thickness 24–160, minimum 48 for two lanes.
- Two rows/columns apply only to application windows. Other components retain one lane.
- Optional application grouping, count badges and per-window selection/context menus.
- Independent hover, focus, focused text and urgent colors, with theme fallback.
- Optional highlight transitions and settings crossfades, off by default, duration 80–1000ms.
- Reopen Settings after changing page animations. Lyrics retain their own animation switch.
