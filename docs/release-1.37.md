# ADWS 1.37 Pre-Release

内部构建：1.37.00。

- 安装器统一全新安装、已有 Niri 集成和旧机迁移三种模式，集中展示依赖、默认应用、配置及服务变更。
- 补齐功能依赖和文字字体检查；默认快捷键参考本机习惯，按目标 Niri 实际能力生成并校验，保留已有输入法、音频与自启动安排。
- 新增个人环境迁移清单、配置版本及冲突审核，保留用户主题和字体，不照搬旧机器的显示器与显卡参数；登录与启动主题保持可选。
- 修复换目录升级丢失图标组布局和旧启动路径残留，迁移顶栏、配色入口与组件库路径，沿用原桌面环境恢复运行组件。
- 配色同步覆盖任务栏、菜单、终端和通知；任务栏应用及默认图标跟随当前图标主题刷新，保留应用原始图标和用户定制。
- 新增带校验与重试的引导入口、预编译组件检查、持久续装及统一结果报告；失败恢复不完整时明确报告并阻止旧计划重复覆盖。
- 修复剪贴板复制等待卡住和任务栏组件尚未加载时过早验收；补充干净 Arch 虚拟机、迁移、取消恢复及安装包完整性检查。

本次仍为预发布。Arch 独立虚拟机和隔离测试的证据见[安装器进度报告](installer-progress-2026-11-06.md)；真实显卡、多显示器、窗口预览及完整实机生命周期尚未全部验收，不声明任何平台已获完整支持。

旧源码目录内的额外自定义资源仍需逐项审核；全新安装自动配置拼音不等于已完成日文、韩文或繁体中文输入方案适配。现有输入法配置保持原状。
