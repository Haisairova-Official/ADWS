# ADWS 安装与交付纲领

状态：执行中。用户于 2026-11-06 确认；本文件是 install.sh 改进的最高产品要求。
此处优先级不替代用户授权：开发和测试不得直接安装软件、修改当前桌面或替换登录管理器。

## 目标与实施顺序

让用户装完即可使用，先保证交付完整，再优化安装界面。

完整依赖与默认配置 → 安装模式与统一流程 → 配置迁移 → 功能验收 → 一键入口与续装。

每项分别记录实现、自动测试和实机验收状态。命令存在、模拟测试通过或开发机可运行，均不等于干净系统验收通过。

## P0：装完不再补东西

- [ ] 明确全新安装、已有 Niri 集成、旧机配置迁移三种模式，各有安装清单。
- [ ] 统一任务栏、窗口预览、截图、剪贴板、输入法、音频、通知、锁屏、壁纸、自动配色的包、配置和服务清单。
- [ ] 提供配套快捷键、窗口规则、启动项的完整 Niri 默认配置；每个默认快捷键均有可执行目标。
- [ ] 检查 Niri 版本及扩展能力，区分官方与分支；按能力生成配置并执行配置校验。
- [ ] 开始时集中选择方案并预览变更；执行中只因失败、新冲突或计划外事项提问。
- [ ] 终端、浏览器、文件管理器、文本编辑器及文件关联一致；所选应用必须已安装。
- [ ] 统一自启动归属，检查 Niri、XDG、用户服务重复启动输入法、任务栏等情况。
- [ ] 实测预览、截图、剪贴板、应用启动、任务栏；失败或待验证不得标为安装完成。

## P1：迁移与视觉一致性

- [ ] 配置版本与迁移规则：保留修改、补齐必需项、列出冲突、可回滚。
- [ ] 安装位置统一解析，消除 ~/ADWS、~/adws 和开发目录硬编码。
- [ ] 按目标硬件生成显示配置；禁止照搬旧机分辨率、缩放、输出标识、显卡参数。
- [ ] 独立个人环境清单覆盖 Shell、主题、插件、别名、字体、光标、头像、昵称及默认应用。
- [ ] 配色链路覆盖任务栏、默认图标、菜单、终端、通知；无需手动重启。
- [ ] 桌面状态测试覆盖平铺／浮动、空工作区、多屏、吸附／悬浮、主题切换。
- [ ] 登录与启动主题是显式可选模块；检测现有管理器、引导方式，处理 SDDM、Plymouth、UKI 静态图冲突，默认保留现状。

## P1：安装过程

- [ ] 一键入口统一检测、镜像选择、下载进度、校验、重试；沿用已有软件源，不重复叠加。
- [ ] Arch 优先匹配的预编译包；不匹配时明确说明并提供源码构建选择。
- [ ] 进度保存在持久目录，重进入口可续装；继续前重新验证已完成步骤。
- [ ] 日志和结果报告列出完成、失败、跳过、待验收、备份位置、注销或重启需求。

## P2：发布门槛

- [ ] 干净 Arch＋Niri 验收首次安装、升级、重复安装、卸载和回滚。
- [ ] 包完整性检查：配置引用的脚本、图标、字体、动态库随包提供或声明依赖。
- [ ] Arch 实机通过才标完整支持；其他发行版按实际证据分级。
- [ ] 暂缓其他桌面适配，优先 Niri 安装、设置、更新、迁移。

## 验收约束

- 无图形会话时可准备安装，但功能状态必须为“待会话验收”。
- 不自动解锁、模拟密码、破坏剪贴板或让锁屏影响当前工作；交互验收须由安装用户触发。
- 软件包操作不可假装可回滚；配置恢复与已安装包必须分别报告。
- 续装不得只信成功标志；校验源版本、安装计划及已安装产物，配置有新修改则报告冲突。
- 不复制旧机硬件配置，不执行迁移的 Shell 文件，不把不明启动项静默删除。
- 发布前按既有流程提交更新概要审核；本纲领不等同于批准 push。
