# ADWS 1.36-B Pre-Release

内部版本：**02** · 构建日期：**2026-11-04**

- 正式加入桌面小组件，与任务栏组件共用模组包管理、独立配置，支持重复添加、拖动缩放、锁定及自定义 CSS。（1.36）
- 新增多屏桌面与文件夹图标组，保留组内网格和相对位置，支持三种背景材质、自定义颜色、图片及透明度。（1.36）
- 新增 ADWS 默认屏幕设置；图标组与桌面组件支持仅本屏幕、仅主屏幕、所有屏幕相同位置，拖动位置按屏幕比例保存。（1.36）
- 重做图标组设置，修复中文输入卡顿、下拉框错位和内容裁切，支持自动配色并禁止滚轮误改。（1.36）
- Niri 显示配置支持按屏幕身份匹配、保存及测试回退；开始菜单每次打开跟随鼠标所在屏幕。（A）
- 修复亮度查询与连续调节导致的整桌面卡顿，改善任务栏吸附圆角及黑角兼容性；多任务窗格新增“关闭所有项目卡”。（A）
- 修复正常源码安装无法在线更新的问题；构建前检测并沿用已有镜像配置，仅中文环境且未配置镜像时询问国内源。（B）
- 安装器支持可选安装 Niri，先识别 SDDM、Plasma Login Manager、GDM 或 LightDM，保留现有桌面与登录配置。（B）

Add reusable desktop widgets, multi-monitor folder groups, display preferences and optional Niri installation. Improve input, popup placement, theme updates, brightness responsiveness and taskbar corners.

Arch x86_64 提供预构建安装包；其他系统使用源码在目标系统构建。

## 使用与迁移

桌面空白处右键创建图标组。齿轮设置名称、关联文件夹、显示器、网格、大小及背景。拖动标题移动整组，拖动图标调整网格，右下角调整大小。移除组不会删除文件。旧桌面目录迁移为默认组，原始布局文件保留。

“ADWS 默认屏幕”控制选择“仅限主屏幕”的图标组和桌面组件。断开显示器时临时回退，保存的原始屏幕和相对位置不变。

Niri 显示页勾选“由 ADWS 保存…”后测试并确认。更改写入 Niri 管理块；原有 output 节点仅迁移被接管显示器，其余属性保留。修改前验证整棵 include 配置树并在 Niri 配置目录留备份。卸载 ADWS 不删除这些系统显示配置。

Cargo 已有源时不询问、不另加镜像；无源配置时仅中文环境询问本次构建是否使用 RsProxy。Rustup 工具链下载源与 Cargo 依赖源分别处理。

背景透明度只影响背景，不淡化图标和文字；真实背景模糊取决于合成器支持。
