# 1.35 Development

分支 / Branch: `Pre-1.35` · 2026-09-28

## 中文

首阶段把插件常驻进程管理迁到 Rust：读取与校验 JSON 行、转发诊断、检测超时和断管、退出时清理插件进程组。Python 继续完成插件包、配置和翻译准备，然后使用 `exec` 替换为 Rust 运行器；插件本体仍可使用 Python。

默认后端仍为 Python。当前安装器和正式发布包尚未自动构建或启用这个实验组件，现有任务栏不会因此被重启。原有插件接口保留；Rust 使用严格 JSON 解析，并限制过深嵌套、单行长度和待发送队列，不保证接受 Python 解析器曾容忍的非标准 JSON。

在项目根目录构建（需要 Rust 1.87+）：

```sh
cargo build --release --locked --manifest-path src/adws-runtime/Cargo.toml
ADWS_PLUGIN_RUNNER=rust ./adws mplg run /path/to/plugin.mplg
```

运行器先查找 `libexec/adws-plugin-runner`，再查找上述构建输出。仅对带该环境变量的进程启用；取消变量或设为 `python` 即恢复原后端。不要直接用内部 `--spec-json` 接口运行普通插件。

验证：

```sh
cargo test --locked --manifest-path src/adws-runtime/Cargo.toml
cargo clippy --locked --manifest-path src/adws-runtime/Cargo.toml --all-targets -- -D warnings
python3 -m unittest discover -s tests -v
```

先构建 release 再运行 Python 测试，才能执行原生进程集成测试；未构建时这些测试会标为跳过。覆盖合法与非法输出、翻译及设置传参、暂停、超时、消费者断开、输出阻塞和信号退出清理。尚未据此宣称性能提升，也未替换桌面、设置、安装器与插件本体。

安装增加“灵魂拷问”：检测 SSH 环境变量、TTY 会话，或没有 Wayland/X11 显示变量时，先询问是否继续，默认取消。确认后才开始依赖检查及安装事务；递归执行安装事务不会重复询问。普通桌面终端不会询问，帮助命令不触发确认。判断依据是会话环境，不验证远程图形服务是否可达。

## English

The first migration stage replaces the resident plugin supervisor with Rust: JSON-lines validation, diagnostics, timeouts, disconnected consumers and process-group cleanup. Python still prepares packages, settings and translations, then uses `exec` to replace itself with the native supervisor. Plugins may remain Python programs.

Python remains the default backend. Installers and release packaging do not yet automatically build or enable this experimental component. Existing taskbars are not restarted. The plugin interface is retained, but strict JSON parsing, nesting limits and bounded line/output queues may reject nonstandard input previously tolerated by Python.

Use Rust 1.87+ and the build command above. Opt in per invocation with `ADWS_PLUGIN_RUNNER=rust`; unset it or choose `python` to restore the original backend. The supervisor is located in `libexec/adws-plugin-runner` first, then the release build directory. Its internal `--spec-json` interface is not a public plugin command.

Build release mode before running the Python test command above; native integration tests otherwise report skips. Tests cover normal and invalid output, localized messages and settings, pauses, timeouts, consumer disconnects, backpressure and signal cleanup. No performance gain is claimed yet; the desktop, settings UI, installer and plugin implementations remain unchanged by this migration.

Installation now asks a playful confirmation question for SSH, TTY or sessions without Wayland/X11 display variables. The default is cancellation, before dependencies or installation changes. Confirmed installation transactions do not ask twice. Normal desktop terminals and help commands are unaffected. Detection uses session environment variables, not a graphical-server connectivity check.
