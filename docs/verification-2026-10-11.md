# 2026-10-11 可靠性与 Mint 验证

基线：已发布的 ADWS 1.35，内部 Q。这次修复尚未发布。

- 托盘信号刷新改为一个在途请求和一个合并后的更新标记，不再取消每个尚未完成的 GetAll。
- 缺失图标文件不抹掉上一张有效图标，也不缓存失败签名；同样的属性可在文件出现后重新加载。
- 安装测试使用可运行的独立 ELF 能力替身，保留真实兼容性探测测试，不依赖宿主 Waybar 的模块。

Arch：托盘信号压力、临时文件恢复、漏注册发现、去重和退出清理 GTK 回归通过；折叠与卸载回归通过；11 项安装测试通过；15 项原生单元测试通过。

Mint 22.3：隔离用户/挂载命名空间 chroot，使用其 Python 3.12.3 与 GTK 3.24。139 项设置、应用缩放、设备控制、更新、安装、字体和日历等回归通过，11 项图形环境条件测试跳过。测试仅使用临时 HOME、运行目录与启动项目录；仅在私有挂载命名空间绑定 /dev/null，未替换 Mint 的系统文件或个人配置。

Mint 自带 Waybar 0.9.24 缺少 cffi/ 和 niri/workspaces。ADWS 兼容性检查准确拒绝该版本，实际使用仍需运行 `adws check --repair-waybar` 安装或构建合适版本。这轮未构建或安装 Mint 的真实 Waybar，也未验证 Mint 的完整 Niri 图形会话。

30 秒 GTK/IPC 压力回归：149050 条事件，1446 次心跳，最大及 P99 心跳间隔 20ms；预热后 RSS 109796 KiB，结束 109560 KiB，未见这段测试内持续内存增长。该结果不能代替数小时真实应用运行的泄漏验证。
