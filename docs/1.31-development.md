## 中文

第一阶段已将插件常驻进程管理迁到 Rust：读取与校验 JSON 行、转发诊断、检测超时和断管、退出时清理插件进程组。Python 继续完成插件包、配置和翻译准备，再用 `exec` 替换为 Rust 运行器；插件本体仍可使用 Python。桌面和设置 GUI 尚未迁移。

插件列表在名称旁显示带代表色的圆角标签（例如 `+ Python`），按插件声明的实现语言显示，不把 Python 插件标为 Rust。旧版原生二进制只声明 `binary` 时显示“原生 / Native”，不猜测其源码语言。标签保留固定内容宽度，插件名称按需省略，按钮仍可使用。

源码安装会构建并原子安装运行器；Arch 预构建流程增加运行器及 SHA-256 校验，仍不要求目标用户安装编译器。源码与预构建更新流程均支持准备运行器。程序内的 `libexec/adws-plugin-runner` 会随更新整体备份/替换，安装失败时也会恢复。

- `ADWS_PLUGIN_RUNNER=auto`（默认）：存在运行器时使用 Rust，否则回退 Python。
- `ADWS_PLUGIN_RUNNER=rust`：明确要求 Rust；缺少二进制时报告错误。
- `ADWS_PLUGIN_RUNNER=python`：明确使用 Python 回退。该后端的退出信号等待问题也已修复。

运行器优先查找 `libexec/adws-plugin-runner`，其次是源码 release 构建目录。后端在插件进程启动时确定；已运行的插件要随任务栏重启才切换。不要直接用内部 `--spec-json` 接口运行普通插件。

开发构建与试用（Rust 1.87+）：

```sh
cargo build --release --locked --manifest-path src/adws-runtime/Cargo.toml
ADWS_PLUGIN_RUNNER=rust ./adws mplg run /path/to/plugin.mplg
```

验证：

```sh
cargo test --locked --manifest-path src/adws-runtime/Cargo.toml
cargo clippy --locked --manifest-path src/adws-runtime/Cargo.toml --all-targets -- -D warnings
python3 -m unittest discover -s tests -v
GDK_BACKEND=x11 xvfb-run -a python3 tests/check_plugin_settings_gui.py
```

先构建 release 再运行 Python 测试，才能执行原生进程集成测试；未构建时这些测试会跳过。覆盖正常/异常输出、设置传参、暂停、超时、慢消费者、断管、信号退出、默认选择和回退，以及安装与更新中的可执行权限和校验失败保护。

Rust 使用严格 JSON 解析，并限制过深嵌套、单行长度和输出队列，不保证接受 Python 解析器曾容忍的非标准 JSON。这一阶段迁移的是运行器，不代表所有插件、GUI 和安装器已经改写，也不能将合成测试的改善比例套用到整个桌面。

安装增加“灵魂拷问”：检测 SSH 环境变量、TTY 会话，或没有 Wayland/X11 显示变量时，先询问是否继续，默认取消。确认后才开始依赖检查及安装事务；递归执行安装事务不会重复询问。普通桌面终端不会询问，帮助命令不触发确认。

## English

The first stage moves resident plugin supervision to Rust: JSON-lines validation, diagnostic forwarding, timeout and disconnect handling, and process-group cleanup. Python still prepares packages, settings and translations, then uses `exec` to replace itself. Plugin implementations, the desktop and settings UI have not been rewritten.

Colored language badges beside plugin names describe their declared implementation, independently of the supervisor. Legacy `binary` entries are labeled Native without guessing their source language. Long names remain ellipsized and action buttons stay visible.

Source installation builds and atomically installs the supervisor. Arch packaging includes the executable and SHA-256 verification without requiring a compiler on the target machine. Source/prebuilt update preparation also stages it. Installation rollback and whole-program update backups cover `libexec/adws-plugin-runner`.

`ADWS_PLUGIN_RUNNER=auto` is the default: prefer Rust when available, otherwise use Python. Explicit `rust` fails if the executable is missing; explicit `python` selects the fallback. Python's termination-signal delay has also been fixed. Backend selection occurs at process startup, so running plugins require a taskbar restart to switch.

The executable is resolved from `libexec` first, then the release build directory. Build with Rust 1.87+ and use the commands above. Build release mode before Python tests; native integration tests otherwise report skips. The private `--spec-json` interface is not a public plugin command.

Strict JSON parsing, nesting limits and bounded line/output queues may reject nonstandard input tolerated by Python. Synthetic supervisor results do not measure total desktop performance.

Installation asks for confirmation in SSH, TTY or sessions without Wayland/X11 display variables, defaulting to cancellation before dependency or configuration changes. Confirmed installation transactions do not ask twice; desktop terminals and help commands are unaffected.

## 2026-09-28 — Start actions and optional upstream Niri compatibility

- Start now offers capability-based power/session actions. Logout/restart/shutdown
  confirm inside the menu; tests use a recording dispatcher and never perform
  real power actions. Search-entry Enter runs the command, while result selection
  remains an application launch.
- Waylander / Traditional / Reversed are independent, explicit keyboard-profile
  changes. Detection, validation, managed include, backup and uninstall restoration
  preserve unrelated bindings. Unsupported upstream builds keep their settings.
- The optional Niri patch is pinned to upstream v26.04 commit
  `8ed0da44d974c32c6877d2f4630c314da0717ecb`; SHA-256 is in its manifest. The builder
  refuses source drift, tests before building release, and installs only a separate
  `niri-adws` command on explicit request. No system compositor or service is replaced.
- Validation: clean patch application to pristine upstream source; upstream Cargo
  check and optimized release build; six focused modifier parser/state-machine/version
  tests; isolated nested-compositor input test showing release-only taps, cancellation
  by chords/click/scroll, and complete key event pairs delivered to a GTK client.
- ADWS validation: 258 Python regressions, GTK settings checks with simulated writes,
  strict start-menu Clippy, power confirmation/cancel tests using a fake executor,
  and three-theme application/command keyboard checks. Live logout, shutdown, suspend
  and a fresh patched TTY login are deliberately not invoked during development tests.
- This remains an optional downstream patch. It has not been submitted upstream.

- Patch identity: **ADWS modifier-taps 1.0.0**, displayed by the built compositor's `--version`; ADWS itself remains **1.31 B**.

## 2026-09-28 — Taskbar responsiveness follow-up

- Moved Start command spawning away from GTK; prioritized homepage shortcuts and
  used an opening ease-out curve. Live Wayland smoke measurement before these
  changes mapped in 125 ms; this measures menu startup, not total click latency.
- Added an independent Rust heartbeat and a bounded pidfd recovery helper. An
  isolated dummy process verified exact-parent termination, diagnostic recording,
  preserved config/style paths and the persisted restart cap. No real taskbar
  hang was induced for that test.
- Added center-segment axial padding and configurable corners. Empty sections
  remain empty; docking retains square corners.
- 262 Python regressions passed, along with the Rust heartbeat test, strict native
  menu Clippy, three-theme keyboard checks and C panel/animation/vertical checks.
- Repeated 1.7–2.4-second main-loop delays were observed before replacing the
  running bar. A sampled Wayland drawing stack included Cairo buffer clipping;
  this is a diagnostic lead, not a proven root cause. The user reported normal
  interaction after loading the updated build. Longer-session stability remains
  something to verify rather than claim complete from this short observation.

- Follow-up: pointed means polygonal < > ends, with independent tip space plus
  5px content padding. All occupied segments now receive the buffer; explicit
  docked selectors square only the outside corners, retaining rounded inner ends. Floating and minimized
  windows, inactive workspaces and other outputs no longer trigger auto-docking.
  Real GtkBox rendering/pixel tests check transparent corners and protected
  content; Rust tests cover tiled/floating/minimized/workspace predicates.
