# Popcat Start button / Popcat 开始按钮

- `closed.png`: default / 默认闭嘴
- `open.png`: hover / 鼠标移入张嘴
- Both are 800 × 930 PNGs with transparency; MNWS scales them proportionally to the taskbar height. / 两图尺寸一致并带透明背景，MNWS 按任务栏高度等比显示。

Original image resources, downloaded unchanged from [Popcat](https://popcat.click/) on 2026-09-18:

- https://popcat.click/img/p.1e9d00be.png
- https://popcat.click/img/op.353767c3.png

These are third-party meme assets; no new license is asserted here. No AI image generation or image editing was used.

In Start settings, choose Image, select `closed.png` as the default and `open.png` as the hover image. Existing launcher commands are retained.

在开始按钮设置选择“图片”，默认图选择 `closed.png`，悬停图选择 `open.png`；启动器命令保持原有配置。
