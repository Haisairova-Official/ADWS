# desktopBasicPack · 桌面基础组件包

包 ID：`org.AkiACG-Community.desktopBasicPack`，版本 **1.0.0**。
包含六个独立桌面组件，没有任务栏入口。需要支持 `desktop.widgets-v1` 的 ADWS 开发版；原版 1.35-R 不包含这个新渲染器。

| 组件 | 功能 |
| --- | --- |
| 时钟 | 电子钟／指针钟；复古、简洁、车站、星环四种钟面；独立秒针开关；时区、12/24 小时制 |
| 计时器 | 倒计时与秒表；开始、暂停、重置；倒计时增加一分钟；结束通知 |
| 2048 | 方向键及屏幕按钮；得分、最高分；单步撤销；新游戏确认；自动存档 |
| 16 格图片拼图 | 4×4 滑块拼图，15 块图片与一个空位；只能移动空位相邻块；保证打乱有解；原图预览、计步、自选图片 |
| 图片展示框 | 自选本地图片、说明文字；完整显示或填满裁切；可调高度 |
| 便签贴 | 中文、多行编辑；输入停顿自动保存；每张最多 20000 字符 |

## 安装和添加

```sh
adws mplg install ./org.AkiACG-Community.desktopBasicPack_1.0.0.mplg
adws config --tab desktop-widgets
```

在“桌面插件配置”中选择组件并添加。六种组件都可以重复添加；每份的设置、位置、CSS、存档互相独立。标题用于拖动，右下角调整大小，菜单可以设置、锁定、复制和移除。2048 点击棋盘后使用方向键，也可以直接点击方向按钮；不会抢占其他应用的方向键。

拼图和相框附带原创山海 SVG 示例，也支持通过“选择图片”使用 PNG、JPEG、WebP、BMP、GIF、SVG。本版显示静态图片，不播放 GIF 动画。图片保留在所选原位置，不复制、不上传；原文件移动或删除后需要重新选择。单文件限制 32 MiB，后台按需缩放解码，最多缓存八张图片。

倒计时保存截止时间，隐藏桌面、重启组件后继续计算剩余时间；暂停保持不变。桌面宿主隐藏时会停止组件进程，期间到期的提醒在再次显示组件后给出；不是关机唤醒闹钟。修改分钟数会更新已暂停的倒计时，运行中的计时保持到本轮结束或手动重置。

每个实例的存档位于：

```text
~/.local/state/adws/desktop-plugins/org.AkiACG-Community.desktopBasicPack/<实例 ID>.json
```

支持 `XDG_STATE_HOME`。隐藏、退出前会尝试提交最后一笔便签；移除组件或卸载模组保留存档。重复添加/复制创建新的独立实例，新的游戏和便签从初始状态开始，不共享旧存档。

## 钟面与紧凑布局

时钟设置先选择电子钟或指针钟，只展示对应选项。指针钟移除外层卡片背景与日期文字，右上方始终显示设置齿轮和更多操作，双击钟面也可打开设置；标题区域仍可拖动；可选择自定义本地钟面图片，圆形裁切并保留透明像素，刻度与数字可单独关闭。清空图片路径恢复内置钟面，图片不存在或无法读取时回退内置钟面并显示提示。图片沿用后台加载与 32 MiB 限制。复古款模拟机械跳秒与轻微回弹，简洁与星环款平滑扫秒，车站款逐秒跳动；关闭秒针后只按分钟刷新。绘制缓存静态钟面，平滑秒针跟随显示器帧时钟，不假定 60 Hz；隐藏、暂停和销毁会移除绘制回调。时区仍跟随系统或指定 IANA 时区。

六个组件采用较小默认尺寸，仍可通过右下角拖动放大：时钟 260×220、计时器 260×240、2048 300×350、拼图 280×410、相框 260×300、便签 260×220（逻辑像素）。保留旧实例的自定义位置和尺寸。安装本包后，添加列表隐藏旧内置时钟入口；已部署的旧时钟仍可正常使用，卸载本包后恢复旧入口。

设置下拉菜单锚定当前按钮，窗口移动与缩放后重新定位。组件设置和 CSS 编辑器使用浮动对话框，在 Niri 中不会成为平铺列。拼图从完成局面通过合法移动打乱；原来的“两块互换”存档会保留选图并重建为可解的滑块局面。

## 自定义 CSS

通过实例菜单的“自定义 CSS”调整外观，颜色默认跟随 ADWS 主题。通用类：`.desktop-interactive`、`.basic-clock`、`.basic-eyebrow`、`.basic-muted`、`.basic-tile`、`.basic-selected`、`.basic-text`、`.basic-clockface`。钟面可用 `@define-color clock_face`、`clock_ink`、`clock_accent` 分别覆盖底色、刻度／指针与秒针颜色。

```css
.desktop-interactive { border-radius: 24px; }
.basic-clock { font-size: 48px; }
.basic-text { font-family: sans-serif; font-size: 18px; }
```

模组只输出声明式界面数据，游戏和计时逻辑在受 Watchdog 监管的独立进程中执行，不在桌面进程中导入模组 Python 代码。无需联网、额外 Python 包、Nerd Fonts 或 GNOME 设置套件。

## 构建

```sh
adws mplg build plugins/desktop-basic-pack
```

自编游戏逻辑和示例插画，MIT 许可证；没有复制第三方小游戏代码或图片素材。
